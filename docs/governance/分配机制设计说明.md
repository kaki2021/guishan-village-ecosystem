# 归山村落 · 分配机制设计说明（商讨草案）

> ⚠️ **本文件是给全体合伙人商讨用的草案，不是协议、不能直接生效。**
> 文件里的所有具体数字都是**初拟值或留空**，**最终由全体合伙人共同商讨决定**。
> **当前经营主体为个体工商户**：个体户在法律上没有"股权"可分，故本文件中的股权（资金股、创业期人力股）现阶段**只作合伙人之间的"内部折股约定"**，靠小程序如实记录、为**将来转为有限责任公司时折算正式股权**做准备（详见第九节）。
> 任何涉及股权、出资、分红、工资的安排，落入正式协议、办理工商登记、处理税务之前，**必须**请懂股权和财税的专业人士（律师 / 会计）审核。本文件只负责把分配的**逻辑和算法**讲清楚，不构成任何法务或财务意见。
>
> 数据来源：本机制用到的出勤、经验值(XP)、出资额，全部来自小程序的任务/日报/出资台账系统，无需额外采集。

---

## 一、最重要的一个区分：劳动 ≠ 股权

很多分配方案一上来就把"干活"直接换成"占股分红"，这其实埋了个坑：万一当年不赚钱甚至亏损，干了一整年活的人，分红是零——等于白干，还替经营风险买了单。

所以本方案把两件**性质不同**的事分开：

| | 是什么 | 怎么来 | 旱涝保收吗 |
|---|---|---|---|
| **工资** | 劳动的报酬，是村子的**成本/负债** | 按岗位 + 出勤 + 投入(XP) | 是。哪怕村子不赚钱，也是欠你的（可先挂账，见第四节） |
| **分红** | 股东的权益，分的是**真利润** | 按**股权**（出资 + 创业期人力股） | 否。赚了才分，亏了认了 |

一个人可以**同时有两个身份**：作为劳动者拿工资，作为股东（出过资、或拿了创业期人力股的）分红。两者各算各的，互不挤占。

> 这样做的好处：① 劳动报酬有保障，不被经营风险绑架；② 分红回归本意，只分真利润；③ 不用再争论"人力该占多少股分红"这种说不清的事——劳动主要靠工资结算。

## 二、股权怎么构成

总股权 100% = 资金股 + 创业期人力股（+ 视需要的预留池）

| 部分 | 占比 | 怎么分 | 数据来源 |
|------|------|--------|----------|
| **资金股** | 【待商讨】 | 按各人**实际出资额**比例 | 出资台账 contributions |
| **创业期人力股** | **初拟 20%（待商讨）** | 创业期内按**出勤 + XP 分档**换取，分完封顶 | worklogs / members.xp |
| 预留池（可选） | 【待商讨，可为 0】 | 留作后续激励、未分配回收等 | — |

**关于创业期人力股（本方案的核心设计）：**

- **为什么要有**：前期没钱、没回报，全靠人扛。这时的人力投入承担着和出资人一样（甚至更大）的风险，只给工资不够——他们应当分享"村子做成了"的长期增值。所以**前期人力换一部分股权**。
- **为什么"封顶 + 限创业期"**：避免"干活无限换股、不断稀释出资人"的失控。做法是——
  - 划定一个**创业期**（如：开业起 ___ 个月 / 到村子首次稳定盈利为止，待商讨）。
  - 创业期内的人力投入，分这个**固定的 20% 池子，分完为止**。
  - **创业期一过，后来的劳动一律走工资制**（第四节），不再换股、不再稀释。
- **怎么分这 20%**：创业期结束时，按各人**全期累计的出勤 + XP 分档**（见第三节同一套档），折算在 20% 池里的份额。扛得久、投入多的，占得多。
- **⚠️ 这 20% 从哪来**：它是从现有股权里**切出来的**——意味着现有出资股东按比例**让渡/稀释**到 80%。这件事必须由现有股东**明确同意**，不能默认。让渡比例、是否所有出资人等比例让渡，待商讨。

## 三、一把尺子：XP 分档（工资和创业股都用它）

工资浮动、创业股分配，**都用同一套 XP 分档**——大家只需就"XP 怎么分档"达成一次共识，两件事就都定了，不用吵两遍。

**前提（地基，必须先做到）**：XP 必须**按"投入的认真工夫/时长"评，不按活的难易/贵贱评**。认真扫一天地和认真拍一天片，XP 应当相近。
（已对应修改 `aiSuggestXp` 评分提示词：去掉"技能门槛/可替代性"等拉开岗位差的维度，主要看投入时长与强度。**此地基未验证稳定前，本机制不应正式用于分钱。**）

**分档方法（以全村 XP 中位数为基准锚定）：**

- **基准线 = 全村达标者的 XP 中位数**（用中位数不用平均数——防一个超活跃的人把均值拉高、把正常干活的人都打进低档）。
- 以中位数为 100%，按各人 XP 相对位置分档：

| 档位 | XP 相对中位数 | 含义 |
|------|------|------|
| 核心档 | > 120% | 明显比中等多投入 |
| 标准档 | 80% ~ 120% | 正常认真干活的大多数（多数人在此） |
| 基础档 | 50% ~ 80% | 投入相对偏少，但在岗 |
| 地板档 | 30% ~ 50% | 在岗但产出明显少，给保底 |
| 复核区 | < 30% | **不自动判**，由主管/股东人工看：真没出力（不计）还是记录漏/特殊情况（补） |

> ±20% 的标准档带宽，让"正常干活的大多数"自然归一档、被当成差不多——贴合"踏实出力大体均分"。只把明显冒尖和明显偏少的区别对待。复核区是护栏：极端值不让算法自动判死，由人确认。

**⚠️ 这套档位的"档间差多大"，是整个方案最关键的旋钮：**
- 档间差小（如核心:基础 = 1.2:1）→ 偏均分，认真干的人收入都差不多。
- 档间差大（如 3:1）→ 偏多劳多得，扛得多的明显高。
- 这正是"大体均分"和"多劳多得"之间的取舍，**由全体商讨定**。建议从小差距起步，跑一段看反应再调。

## 四、工资怎么算（含"初期没钱"怎么办）

- **基准档月工资：初拟 5000（待商讨）**。这是"标准档/满勤"的基准，其他档按第三节的 XP 档**上下浮动**（浮动幅度＝档间倍数，待商讨）。
- **出勤门槛**：当月有效工作日不足 ___（待商讨）的，按比例减记或不记当月工资。有效工作日 = 当天有"主管确认完成的任务"（来自 worklogs，最难灌水）。
- **⚠️ 初期没钱怎么发——挂账，不付现**：
  1. 每月照常按上面规则**算出**每人应得工资。
  2. 村子没钱，就**先记成"欠员工的钱"（应付工资）挂在账上，不实际发现金**。人虽没拿到钱，但账上明确记着村子欠他多少。
  3. 等村子有了收入，**优先补发这些挂账工资**；工资补齐后还有余，才是利润、才进第五节的分红。
- 这样"劳动有成本"就落到了实处（挂账工资是村子的负债），"初期没钱"也不影响——贡献被记下、村子认这笔账。

## 五、分红怎么算

- **前提**：先把当期挂账工资补发完、覆盖各项成本后，**有剩余利润**才分红。亏损或无利润年份，不分红（但工资该挂的照挂、该补的照补）。
- **按谁分**：按**股权**分——即"资金股 + 创业期人力股"合并后的总持股比例。出资多的、创业期扛得多换到人力股的，分得多。
- **只分利润、不分固定资产**。
- **时效**：分红是按当期利润分配，不是永久躺分；持股本身长期有效（股就是股），但每期分多少看每期利润。

## 八、还没解决 / 必须找专业意见的点

- **法律与税务结构**：以上是"内部分配口径"。落到工商登记的股权结构、合伙协议条款、工资的社保个税处理、分红的税务，**必须请专业人士**。本文件不替代法律/财税意见。
- **XP 评分地基未验证**：第三节那条"XP 按投入评"虽已改提示词，但**需真机跑一段、确认"认真干 XP 确实相近"后**，本机制才可正式用于分钱。
- **冷启动期数据不稳**：村子刚起步、人少时，XP 中位数样本太小、不稳定。建议**创业最早期先用一个简单过渡办法**（如全员均记同档工资），等人数和数据稳定后再切到本机制。
- **"挂账工资"的法律性质**：员工与村子之间"欠薪挂账"在法律上如何认定、有无风险，需专业人士确认——尤其涉及非合伙人的纯雇佣劳动者时。

## 九、经营主体与阶段（个体户 → 公司）

### 现阶段：个体工商户

个体工商户法律上**没有"股权"可分**，且对外承担**无限责任**（欠债时登记经营者要用个人全部财产偿还）。所以现阶段：

- **本文件里的"股权"（资金股、创业期人力股）只是合伙人之间的"内部折股约定"**——不是工商登记的真股，只是大家白纸黑字认下的一本"将来折股的账"。
- 这本账的作用：**如实记录创业期谁出了多少资、谁扛了多少活(出勤+XP)，等将来转公司时，照这本账折算成真正的公司股权。**
- 现阶段最重要的动作，就是**老老实实记账**——小程序的出资台账、日报/XP 数据，现在的核心价值就是当这本"折股依据"的账本。转公司那天，这些数据就是分股权的铁证，不靠回忆、不靠拍脑袋。

⚠️ **必须现在就说清的风险**：
- **无限责任在转公司前一直都在**。这期间生意欠债，是登记经营者**个人全部财产**兜底；其他合伙人在工商上不是股东、法律上不担这个责——**等于登记人独自扛着法律风险，其他人却已在内部账里占着"股"。** 这个风险错位，必须在内部协议里写明**债务怎么分担**，别等出事才发现登记人背锅。
- 现阶段几个人之间的"分钱"，本质是私分经营者的个人所得，**不是规范的公司分红**，法律保护力弱。务必有一份**签字的内部协议**兜底。

### 将来：转为有限责任公司

等生意跑顺、确定长期合伙，转成有限责任公司——那时本文件第二、五节的股权与分红设计才**真正生效**：

- 把内部账本里记的出资、创业期人力贡献，**正式折算成注册资本里的股权**，工商登记、签正式章程/协议。
- 有限责任能把个人财产和经营风险**隔开**，不再是无限责任。
- ⚠️ 从"个体户私下分钱"到"公司股东分红"，**税务和账务处理不一样**，转换那一刻怎么把账平掉、怎么处理税，**务必找会计/律师**——这是转公司时最容易踩的坑。

### 数据怎么固化成凭证（让小程序数据"算数"）

**小程序数据是会变的、可被改、可能丢——所以它只是"记录工具"，不是分配"准绳"。** 真正算数的，是定期导出、各方签字确认后冻结的纸面/电子凭证。规则：

1. **每月底**：从小程序导出当月三样——① 各人有效工作日；② 各人 XP（当月 + 累计）；③ 当月出资变动。打印或存 PDF。
2. **各合伙人核对无误后签字**（线下签纸最稳；或微信群各自明确确认 + 截图存档，但正式场合仍建议签纸）。
3. **签字版归档**（纸质 + 电子各一份）。这份**月度签字凭证**，才是有效力的"账"——小程序只是它的来源。
4. **年底做一份全年汇总**，作为当年工资结算、分红/折股的**最终准绳**。月度签字是过程留痕，年度汇总是结算依据。

> 协议里的写法应是：「分配以**双方签字确认的月度/年度导出记录**为准，小程序仅作日常记录工具」——**不要**写成"以小程序数据为准"（系统数据单方可改、易被质疑，扛不住纠纷）。
>
> （小程序目前已能导出周报/出勤概览；如需"按月导出明细"的专门功能，可后续补一个导出按钮。）
