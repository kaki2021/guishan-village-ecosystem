# 文档导航

仓库把资料分为“整理版总览”和“原始讨论稿”两层。第一次了解项目建议先读 [生态总览](ECOSYSTEM_OVERVIEW.md)，需要追溯具体思路时再进入各主题文件。

## 愿景与产品路径

- [生态总览](ECOSYSTEM_OVERVIEW.md)：从全部资料中提炼出的公开入口，说明定位、六模块、参与路径、路线图和边界。
- [新村落文明](vision/新村落文明.md)：六模块生态的完整愿景稿。
- [项目理念与参与指南](vision/项目理念与参与指南.md)：说明项目为什么开始、目前在做什么，以及不同的人可以怎样参与。
- [山野生活适应计划](vision/山野生活适应计划.md)：说明从短期体验到长期共建的参与路径和建设顺序。
- [《新村落文明》PDF](assets/新村落文明.pdf)：原始排版版资料。

## 教育

- [生态村教育执行方案](education/生态村教育执行方案.md)：真实项目驱动、分层学习循环、AI 辅助与评估工具。
- [职业底层结构树](education/职业底层结构树.md)：从信息、生命、物质、能量和关系五类对象理解职业与能力迁移。

这些内容属于教育实践设计，不代表学历教育资质或升学承诺。涉及未成年人时，需要另行落实监护、安全、师资和合规责任。

## 分配与治理

- [分配机制设计说明](governance/分配机制设计说明.md)：解释劳动、工资、分红、股权和数据凭证之间的区别。
- [分配机制方案](governance/分配机制方案.md)：偏制度文本的商讨版本。

两份文件均为讨论稿，不构成投资邀约、股权承诺、劳动合同或法律意见。正式实施前，应由全体相关参与者协商，并经过法律与财税专业审查。

## 产品与技术

- [对外小程序项目说明](product/对外小程序项目说明.md)：页面、云函数、数据模型、权限、内容审核和已知技术经验。
- 仓库根目录 [README](../README.md)：公开配置、部署步骤和安全边界。

## 阅读提示

- 文档来自不同阶段，部分表达是设想、路线或历史设计，不等于当前已上线功能。
- 当文档与代码不一致时，以当前代码和根目录 README 的配置说明为准。
- “对外小程序”与内部库存、任务、工时、金库等运营工具是两套系统，不要混用身份、积分或数据凭证。
