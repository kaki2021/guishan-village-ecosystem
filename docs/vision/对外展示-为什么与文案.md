# 归山村落 · 对外展示「为什么」交付稿

> 这份只管**展示层**——对外那页该说什么、怎么摆。
> 运营层的账(带得起几个人、转化率多少)是你后台的事,不进门面,也不在这份里。

---

## 一、为什么(脊柱)

整套对外说法挂在四条腿上。每条腿都带一个**边界**——边界不是退缩,是它打不穿的原因。一句话只要敢认下自己的边界,就没人能拿反例把它捶碎。

1. **时代问题**:AI 在抽薄劳动的价值 → 同时是**生存**问题(钱从哪来)和**精神**问题(人为什么活)。
   *边界:这事正在发生、还没全到——所以是趁早动手,不是已经晚了。*

2. **AI 是工具**:它把小规模乡村过去算不过来的「协调成本」头一回打了下来。
   *边界:它降的是协调成本,不替你种那季稻。*

3. **乡村是地板**:有地、低成本,把「够」的价格压低,让人不必再被收入的跑步机绑着。
   *边界:给够得着的人,不是给所有人。*

4. **网络是杠杆**:可复制的是方法 + 品牌,从一个点长成一张网。
   *边界:复制的是模式,兑现在后期。*

**一句贯穿线:**
> 趁城市还需要你的时候,提前为城市不再需要你的那天,建好一块够得着的地板。

**两条压在底下、决定语气的判断(别忘):**
- **问题面向所有人,出路面向少数。** 大问题才有共鸣,小出路才不被反例打穿。
- **真门槛不是钱、不是技能(都能慢慢长出来),是「能自己拿主意、自己下场、自己找到位置」的人。** 你不用替他设门槛,他自己就是那道门槛。

### 📄 about 页(理念 / 为什么 / 大方向 / 阶段)

**〔问题 · 面向所有人〕**

AI 来了,而且它先动的不是工厂流水线,是写字楼。靠脑子换工资的那些活,正在一点点变得不值钱。这一代人原本以为最稳的那条路,现在没那么稳了。钱越来越难挣,人越来越焦虑,而且这焦虑还是空的:你也忙也累,可说不太清自己到底在为什么使劲。

说到底这是两件事。一件是怎么活下去——钱从哪来。另一件是人为什么活——意义在哪。城里很多东西是空对空的;山里不一样,你干的每件事都看得见摸得着:种地、做饭、修房子,把村里的老人和撂荒的地重新接上。

**〔AI 的另一面 · 它也松开了你〕**

AI 抢饭碗是一面,可它还有另一面:它把很多事的门槛拉平了。以前不会写代码的人,现在能让 AI 帮着写出能用的东西;不会画画的人,能把脑子里的想法变成画面;一个人靠着 AI,能干过去得一整个团队、还得待在城里才干得了的活。它不会自动帮你把活干得多漂亮,但它让你「开始做得了」——打掉的是门槛,不是水准。

这件事对农村,可能比对城市意义还大。过去在山里你能干的,无非种地、做点小生意、接待客人;那些来钱的、有意思的活——做内容、做设计、做电商、做线上的买卖——基本都得进城才有得做。现在这些事在山上也能做了。所以 AI 时代的农村,不该再被当成一个单调的地方,它其实可以很丰富。这还顺带松开了一个老结:你的收入不必全押在「城里人愿不愿意上山」这一条上,你在山里做出来的东西,卖到哪儿都行。

AI 也帮了乡村一个一直以来的难处:散。地散、户散、房散,过去一小群人根本张罗不过来,要么靠大集体,要么靠堆人力。现在这种「协调」的成本被压下来了,集中育苗、排活、调度,几个人也忙得过来、也算得过账。活儿可以先用手干,等哪样实在重复、实在缺人了,再往机械、自动化、AI 上推一格。我们这套小程序已经有了雏形,所以「最后都接到一个接口上」不是从零开始。

**〔这里能给你什么 · 也给不了什么 · 诚实〕**

把城市最缺、这儿最不缺的摆出来——这些不是说辞,是这座山本来就长在这儿的:

- **干净的水、干净的空气、真正的安静**——它们本身就是产品。
- **吃得到源头**:自家种的菜、自家养的蛋禽塘鱼、山里的菌,饭是地里长出来的。
- **有归属**:一起种、一起吃、一起议事过节——这种东西,城里花钱也难买。
- **有意义的活**:你干的每件事都看得见结果,而不是空对空。这是这套生活里最稀缺、也最难被 AI 替掉的部分。

也得把给不了的说清楚,省得你白跑一趟:

- 正规学籍、中高考这条路,这儿给不了——有学龄孩子要走体制内的家庭,得先想清楚。
- 急重症、专科,山上接不住,得往城里送——把这点纳入考虑。

说这些不是劝退,是想让真正合适的人,来之前就知道自己图的是什么。

**〔大方向 · 路线图 · 诚实,不露账〕**

金佛山·风吹岭是起点,不是终点。我们要做的,是一套能复制的「新村落」。它分四步长大——每一步这地方会变成什么样,你都能看见自己在哪儿接进来。

**第一步 · 扎根(现在 ~ 一两年)**
*在做的事*:把撂荒的荒田重新种起来、把山泉水引下来、把共食食堂开起来(自家菜,客人和村里老人一桌吃)、和乡亲一起把闲下来的地和闲下来的手接上。
*现在长这样*:民宿、露营在跑,食堂刚起步,大部分活还得自己上手——很糙,但每一件都是真的。
*你能怎么上车*:来当客人住一阵,边住边看;会种地、做饭、修房、张罗人的,来了马上有活;没手艺、肯学的,我们一带一。

**第二步 · 长起来(一两年后)**
*在做的事*:种的地连成片、按活儿分工、集中育苗;食堂升成中央厨房,观光车把人从山下接上来,给村里老人送饭到家;开始有「养」和「教」;成立合作社——**一起干、一起分,只有真正下场干活的人,才有分配的话语权。**
*你能怎么上车*:从客人转成共建者的路,这一步最宽;想长住、想参与「这事怎么管」的,这时候进正好。

**第三步 · 连成网(三五年后)**
*在做的事*:用一套小程序 + AI 把这张碎网协调起来——地块、房态、订餐、预约都在一个接口上;养、教、医融进日常;把「这事到底怎么干」沉淀成一套能复制的方法。
*你能怎么上车*:懂数据软件、懂治理财务、能把经验变成方法的人,这一步是主力。

**远方 · 一个点,长成一张网**
金佛山是第一个点。这套方法如果真跑通,能复制到别的村、别的山。可复制的从来不是好山好水(哪儿都有),是一群认同这种活法的人 + 一套怎么干的方法——这是最难抄、也最值钱的。
说句老实话:**这是远方,不是明天。我们现在还在第一步刨地。** 写出来是想让你看清这条路通向哪,不是假装已经走到了。

**〔为什么是现在 · 出路 · 诚实,筛人〕**

我们不假装能解决所有人的问题,也不信哪座山能接住一场时代的冲击。我们只在做一件具体的事:**趁城市还付得起的时候,提前在乡村建好一块够得着的地板**——有地、低成本、活得下去。

失业不是一天到的,它分批来。聪明的做法,是在它够到你之前,手里先多一条路。这条路不替你发财,但它接得住你。它要的不是你有多少钱、会不会种地——这些都能在这儿慢慢长出来。它只挑一样:**你得是个能自己拿主意、自己下场、自己找到位置的人。**

是,就来。剩下的,你自己会判断。

### 📄 需求全景(对外版 · 可做独立页,或接在 about 之后)

> 这页干三件事:让你看清山里到底缺什么、又不缺什么(**不吓人**);让你看见我们每一项都想过怎么解(**实在**);也顺便让你照见——你以前花最多钱追的好多东西,可能根本不在这张表上(**一面镜子**)。
> 〔注:这是把「需求系统图」翻成对外语气。完整带「进口依赖 / 谁能常住」的那版留后台,这版只老实摆「缺什么、怎么解、缺谁」。〕

一个人真正需要的,其实就这么四层。城里把它们搅在一起、还塞进一堆其实并不需要的;山里反倒把它们一层层摆清楚了。

**第 0 层 · 活下去**(断了就活不了——这层在山上反而最扎实)
水:山泉引流、蓄水过滤,近乎全自给 · 主食:薯类、玉米这海拔正合适,大米还得买一部分 · 副食:高山菜、蛋、禽、塘鱼、菌,可高度自给 · 住:空间是现成的,木石就地取,水泥钢筋玻璃靠买 · 电:光伏 + 储能,电网补充 · 取暖做饭:柴薪、太阳能热水,瓶装气兜底 · 干净的水、空气、安静:本身就是产品。
→ *想下场的话,这层最缺:会种地的、懂水电木工的多面手。*

**第 1 层 · 过得安稳**(长住必须)
日常医疗:中医调理、慢病管理、基础急救做得到 · 急症 / 专科:山上先稳住、往城里送——老实说这层接不住,我们靠的是转运预案,不装作能搞定 · 卫生污废:堆肥、沼气、厨余还田 · 衣物:基本靠买(这不是与世隔绝的乌托邦)· 出行物流:电瓶车跑短途,油料和大件靠买 · 通讯网络:接外部基础设施,正常上网 · 现金:把山里的体验、农产、内容卖给城市,换回买能源材料的钱——**我们和城市是来往,不是搬进深山断网**。
→ *这层最缺:受过训的急救员、会调度物流的、能管钱理账的。*

**第 2 层 · 过得有意思**(常住了才谈得上)
教育:技能传承、自然教育、共学都有;但正规学籍、中高考这条路给不了——有学龄孩子要走体制内的,得先想清楚 · 社交归属:共创、共食、议事、过节,近乎全自给 · 文化精神:在地文化、仪式感、和自然的连接 · 休闲:山野徒步、手作、看星看瀑 · 健康运动:山地行走、劳作本身就是运动。
→ *这层最缺:能带共学的老师、会张罗气氛的、做内容策划的。*

**第 3 层 · 活得有根**(社区的灵魂——几乎全在山里产生)
意义与参与:有意义的劳动、参与式所有权 · 创造与成长:农艺、手作、运营,内部传帮带 · 自治与分配:一起议事、合作社治理,只有真正下场干活的人,才有分配的话语权。
→ *这层最缺:能守护社群、主持议事的人;懂治理和分配的人。*

照完这四层,你大概会发现两件事:**一,山里没你想的那么吓人——每一项缺口都有解,连"解不了的"我们都老实标出来了;二,你在城里花最多钱追的那些,好多压根不在这四层里。** 这两件,就是我们想让你来之前先看清的。

## 三、怎么在小程序里摆

你 app 里已经有现成的容器,基本不用新造页,只往里填内容:

| 内容块 | 落在小程序哪一页 | 状态 / 怎么接 |
|---|---|---|
| **为什么**(时代 / AI / 地板 / 为什么是现在) | about 页(理念) | 已有页,填文案;首页理念卡点进去就是 |
| **需求全景**(四层 · 诚实) | about 内一节,或单独一屏 | 新内容,静态页就行;每层「最缺谁」可跳 join |
| **路线图**(四步 · 你能怎么上车) | about 页「大方向」那段 | 已写进 about 文案 |
| **招募 / 技能三档 + 入场方式** | join 页(加入我们) | 已有,`joins` 加一个 `skills` 字段 |
| **山野生活适应计划**(四入口 + 玩法) | 新入口（首页重组）+ 复用 `activities`/`enrolls` | 详见《适应计划 · 功能规划》那份文件 |

**整条漏斗的顺序**(别让这些内容各自孤立):
`about(为什么 → 需求全景 → 路线图)→ 适应计划(四入口:先来住 / 认一份 / 学一点 / 留位置)→ 报名 / 旅人证(身份在长)→ join(深度共建)`

**结构(轻,别堆):**

- **about 页**:一屏一段往下滚 —— 问题 → AI 两张脸 → 这里能给你什么 → 需求全景四层 → 大方向四步 → 「为什么是现在」+「加入我们」按钮。(需求全景若嫌长,拆成独立页,about 里留个入口。)
- **join 页**:三种进来的方式 → 我们在做的事(想法) → 技能三档(🔥/⏳/🌱,做成可点标签) → 提交意向。技能标签点选后带进表单,`joins` 加一个 `skills` 字段即可。
- **适应计划**:四入口做成首页主结构,玩法挂在入口下;**第 0 批(体验卡 / 小课 / 试住营 / 适应包)就是把已有报名换包装上架**,零工程。详见功能规划文件。
- **首页理念卡**的钩子语,从大方向里抽最狠那句:**「趁城市还需要你的时候,提前建好一块够得着的地板」**。

**红线 —— 这些绝对不进门面(我们吵过的):**

- ❌ 第一阶段预算、转化漏斗数字、「多数体验客不会转常住」——这些是对内的诚实,对外是劝退。
- ❌ 地分类、合规路径、关系地图、「投名状 = 喂老人」——村集体战术,**公开会反伤**。想法可以亮「我们在做食堂 / 接送」,但破冰动机是你自己的牌,不写。
- ❌ 「等死 / 唯一 / 最优解 / 避难所」这类过度声称,以及「那种人很少、城市也活不了」这类靠贬低别人来证明门槛低的话——会精确赶走你最想要的、有判断力也有自尊的人。

**一条能自己用的判准(下次再纠结「这能不能公开」时):**

写之前问这句在讲什么——
- 在讲「**我们在做什么 / 你能接什么**」 → **公开**(种地、食堂、接驳、合作社的存在、「只有劳动者投票」这条原则,都该大方亮出来)。
- 在讲「**我怎么算计 / 我哪儿脆弱 / 我有多少钱**」 → **收起来**(投名状、摸底、不签大协议、怕踩基本农田、村两委换届、几万/十万/百万)。

同一件事常常两头都有,一刀切开:
- **食堂**:动作公开;「这是给村里的投名状」收起来。
- **合作社**:存在和「劳动者才有话语权」公开;「挂靠 / 分红载体 / 法律容器」这套机制收起来。
- **和村里的关系**:「互相需要、一起盘活撂荒地和留守老人」公开;「关系怎么经营、先给什么后要什么」收起来。

## 附:关于「需求系统图」和「分阶段路线图」(你问的那两张)

这两张现在**都上了门面**,各只留一小块在后台——分法就是那条判准:

- **需求系统图** → 翻成「需求全景(对外版)」放进 about(见上)。**老实摆「缺什么、怎么解、缺谁」,正是它最有说服力的地方**(不吓人 / 实在 / 照镜子)。只有两格换了说法、没照搬:「收入与现金」讲成「和城市来往」而不是「靠城市续命」;完整表里「进口依赖 / 谁能常住」那种战略性脆弱标注,留作深聊。
- **分阶段路线图** → 「四步 · 你能怎么上车」放进 about,「四阶段成长(手工 → 器械 → 自动化 → AI)」放进 AI 那段。只有**逐项预算**留后台:对外只说「起步一两万就能动起来」这个量级(它正好证明门槛低),不报「农业 ¥7300」这种会被对账的清单。

**那张完整的需求图别浪费**——它是你的**深聊材料**:一个认真的人举了手、进了一对一,把带「进口依赖 / 谁能常住 / 预算」的全图摊给他看,正好证明你把整套系统(水电医食教治理)从头想透了。对你最想要的那种系统思维的人,是最强的信任状。**门面给对外版,深聊给全图。**

> 想把「四阶段成长」或「需求四层」做成小程序里能点的小图,都可以——做干净版(带解法、带「缺谁」),别把带预算、带「谁能常住」筛选机制的那版交互整张搬上去。
