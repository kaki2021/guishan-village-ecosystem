# 归山村落生态总览

## 一句话定位

归山村落是一套以山野节点为载体、让人从短期体验逐步走向持续参与和共同建设的生活协作网络。

它的核心表达是：

> 不是逃离城市，是建立另一种文明的参照系。

这里的“参照系”不是抽象口号，而是一组可以被体验和验证的日常：真实的土地与食物、适度劳动、人与人的互助、自然节律，以及能让参与者逐渐承担责任的协作机制。

## 回应的问题

归山村落关注的不是单一产品机会，而是几组相互关联的现实问题：

- 城市生活节奏与身体恢复之间的矛盾。
- 知识获取越来越容易，但真实判断、动手和协作能力更难形成。
- 人与食物、土地、季节和地方文化之间的连接逐渐变弱。
- 乡村存在闲置空间与土地，却缺少长期参与者和可持续的组织方式。
- 人们希望拥有更多生活选择，但从“来看看”到“真正参与”之间缺少清晰路径。

因此，项目不把自己定义成单一民宿、农场、课程或社群，而是尝试把这些要素组织成可持续的生态。

## 六个模块

| 模块 | 解决的问题 | 在系统中的作用 |
| --- | --- | --- |
| 旅 | 怎样让陌生人低门槛抵达和理解这里 | 入口：短住、活动、路线和体验 |
| 养 | 怎样恢复更稳定的生活节律 | 日常主体：饮食、作息、环境和适度劳动 |
| 教 | 怎样在真实生活中发展长期能力 | 深水区：项目制学习、生产实践和跨领域迁移 |
| 农 | 怎样守护土地并提供真实物质基础 | 底盘：种植、食材、生态维护和课程场景 |
| 医 | 怎样获得合规、连续的健康支持 | 支持层：由有资质人员依法提供专业服务 |
| 文 | 怎样形成共同语言与精神根基 | 内核：地方文化、节气、传统知识和公共表达 |

六个模块不是六条互不相干的业务线。旅让人进入，农提供物质基础，养和医支持生活状态，教把真实生活转化为能力，文帮助参与者理解共同生活为何值得。每个节点可以根据自身条件选择重点，不必一次配齐全部模块。

## 参与路径

对外产品应先把参与路径讲清楚，再决定增加多少功能：

1. **了解**：看到理念、节点、人物和正在发生的事。
2. **到场**：通过短住、活动或课程获得第一次真实体验。
3. **持续参与**：形成旅人身份、参与记录和与某个节点的关系。
4. **承担责任**：成为授权成员、长期驻留者、共创伙伴或节点负责人。
5. **复制经验**：把成熟的课程、运营经验和协作规则带到其他节点。

近期可以用四个入口承载这条路径：

- **先来住**：短期体验、周末归山、山居适应营。
- **学一点**：山野技能、自然观察、真实生产生活课程。
- **认一份**：在关系稳定后探索认养或长期支持，避免一开始就滑向普通电商。
- **留下位置**：值日、任务、试住、长期驻留和共建申请。

任务、积分、认养不是越早越好。先用已有内容和活动验证真实需求，再增加新的数据模型与规则，可以避免系统很复杂却没有持续参与者。

## 从单点到网络

一个节点要先解决自身的基本循环：有人到场、有人留下、土地与空间被维护、活动能够持续、账目与责任清楚。单点稳定之后，再考虑节点之间的网络关系：

- 访客可以在不同节点间流动。
- 老师、课程、物资和运营经验可以复用。
- 每个节点保留地方特色，同时共享最小的身份、内容和协作协议。
- 软件负责降低协调成本，不代替现场关系、人工审核和共同决策。

## 分阶段路线

### 第一阶段：扎根

把住宿、共食、活动、荒田复耕、山泉和基础空间维护做成可持续的日常，让第一个节点真实运转。

### 第二阶段：长起来

形成稳定的角色分工与产业协作，逐步发展农业、教育、健康支持和共同生活服务，并建立基本的财务与责任边界。

### 第三阶段：连成网

用小程序、数据与 AI 辅助节点之间的信息流动、内容分发和经验复用，但仍由人对关键决定负责。

### 第四阶段：去远方

在不同地区形成能够独立运转又彼此协作的节点网络，让更多人能在合理距离内抵达一个真实的山野生活入口。

## 软件在生态中的位置

本仓库的小程序是对外入口，主要解决：

- 把理念、节点、活动和内容放在同一套叙事中。
- 让访客从浏览走到报名、从一次到场走到持续身份。
- 为节点运营者提供内容、活动、成员和申请管理。
- 用有限权限和内容审核控制公开发布风险。
- 为未来多节点网络保留统一的数据结构。

软件不应替代内部运营系统。库存、采购、工时、资金、分配和治理属于另一套更严肃的凭证系统；公开互动等级也不能自动转换成劳动股权或治理权。

## 必须守住的边界

- 不把愿景包装成已经完成的事实；每个阶段都要用真实运营数据检验。
- 不把山野生活浪漫化成万能解决方案，也不贬低城市生活。
- 健康相关内容不能替代医疗诊断和治疗；专业服务必须依法由有资质人员提供。
- 教育实践不等于国家学历教育，面向未成年人时应遵守安全、监护和教育相关要求。
- 分配、股权和治理文档是讨论稿，正式实施前必须形成清晰合同、章程与财税安排。
- AI 只做整理、推荐和辅助表达，不编造节点、活动，不计算金额，不替代医疗、法律或治理决定。
