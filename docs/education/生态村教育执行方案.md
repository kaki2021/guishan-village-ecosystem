# 生态村教育执行方案 v2.0

> 核心假设：所有专业/领域 = 结构 + 参数。教育的本质是让人习得结构识别能力，而不是记住参数。
>
> v2.0 新增：五维发展手册（第九节），整合归墟场论知识库 + 《阴符七术》训练体系。

---

## 一、设计原则

### 1.1 三个不做

- 不以年龄分班，以"循环完成次数"分层
- 不以考试评分，以"能否把结构教给别人"评估
- 不以知识点排课，以"最小循环体"排课

### 1.2 两个核心机制

**机制一：结构先于内容**
每个新领域的第一课不是"这个领域有多重要"，而是"这个领域的最小循环体是什么"。先跑一遍，再讲原理。

**机制二：螺旋而非台阶**
教育不是从第一层爬到第六层，而是在同一个结构上反复放大尺度。发酵的结构 = 中医辨证的结构 = 代码模块化的结构——认出这个"同一个"才是真正的学会。

---

## 二、学习层级（六层螺旋）

| 层级 | 名称 | 核心任务 | 典型产出 |
|---|---|---|---|
| L1 | 最小循环体 | 手感 + 因果直觉 | 能独立完成一次完整操作 |
| L2 | 参数对比 | 控制变量意识 | 三栏测试报告（参数/结果/差异） |
| L3 | 循环串联 | 接口问题意识 | 5个循环串成一个真实闭环 |
| L4 | 领域结构 | 提炼领域骨架 | 能用一句话说出该领域的"最小循环体" |
| L5 | 跨领域迁移 | 结构同型识别 | 能主动说"这跟那个是同一个结构" |
| L6 | 价值判断 | 带价值观驱动结构 | 能用结构分析做真实决策 |

---

## 三、最小循环体内部的10步（十天干模型）

> 每次循环体内部不是一个黑盒，有可观察的10个阶段。教师的任务是识别学习者当前在哪一步，而不是催他跳过。

| 阶段 | 名称 | 学习者状态 | 教师动作 |
|---|---|---|---|
| 甲 | 盲探 | 乱试，不知道变量 | 给材料，不给方向 |
| 乙 | 定向 | 开始区分"有用/没用" | 引导提问：你注意到什么不同？ |
| 丙 | 反馈校准 | 根据结果修正操作 | 创造快速反馈条件 |
| 丁 | 破壳 | 第一次主动预测结果 | 让他预测后再做 |
| **戊** | **过滤/边界形成** | **"我知道为什么了"** | **这是关键关口，标记它，不要赶他走** |
| 己 | 共识提炼 | 能说出规律 | 让他教别人 |
| 庚 | 方案固化 | 能写出SOP | 要求他整理操作手册 |
| 辛 | 稳定运行 | 不需要思考就能做对 | 给更难的参数 |
| 壬 | 晶格化 | 该循环变成本能 | 准备下一个更大尺度的循环 |
| 癸 | 跃迁 | 能把这个循环的结构迁移到新领域 | 跃迁仪式（见第五节） |

> **戊阶段特别说明**：这是从"执行参数"变成"识别结构"的分水岭。大多数传统教育在丙/丁就停了（会做题），真正的理解在戊之后才开始。不要因为进度压力跳过它。

## 四、课程排期（一学期示例）

### 4.1 单领域深度（8周）

以**发酵**为例（可替换为任意领域）：

| 周次 | 任务 | 阶段 | 产出 |
|---|---|---|---|
| 第1周 | 做酸奶（不给温度提示） | 甲-乙 | 失败记录 |
| 第2周 | 改变温度重做，对比结果 | 乙-丙 | 三栏报告 |
| 第3周 | 换原料（豆浆/椰奶），预测结果 | 丙-丁 | 预测+验证报告 |
| 第4周 | 小组对比实验（矩阵化参数） | 丁 | 参数矩阵表 |
| 第5周 | 讨论：为什么温度/菌种/时间是关键变量？ | 戊 | 口头/书面表达"我理解了什么" |
| 第6周 | 做一个新的发酵产品（自选：面包/酱/泡菜） | 己-庚 | 迁移操作手册 |
| 第7周 | 把流程教给新来的孩子 | 辛 | 教学记录 |
| 第8周 | 跨领域讨论：发酵结构 = 什么结构？ | 癸准备 | 结构类比文档 |

### 4.2 多领域串联（一学年）

每学期跑5个最小循环体，刻意横跨不同领域：

| 学期 | 5个循环体 | 串联集成项目 |
|---|---|---|
| 秋学期 | 发酵、种植、木工、账目、AI工具 | 农产品摊位（种→加工→销售→记账） |
| 冬学期 | 中医基础、养殖、烹饪、编程、纺织 | 家庭健康记录系统（观察→记录→分析→干预） |
| 春学期 | 建造、水电基础、地图/测量、契约、历史 | 设计并建造一个小型功能空间 |

## 五、三个核心工具

### 5.1 三栏测试报告（L2标配）

每次完成操作后填写：

```
【这次什么参数】
温度：30°C，时间：12小时，菌种：市售酸奶

【结果】
凝固，偏酸，表面有少量气泡

【和上次差在哪里】
上次24°C/14小时，没有气泡，酸度适中
→ 推测：温度高了导致发酵过快，气泡是CO2
```

### 5.2 系统结构观察清单（L5标配）

当孩子接触一个陌生系统时，用七个问题快速定位它的结构：

1. **收敛核**：谁/什么是这个系统的中心？
2. **发散场**：它向外释放什么？
3. **立极点**：内部和外部的切换界面是什么？
4. **膜**：它和外部的边界是什么？
5. **收发互补**：它和谁能量互通？
6. **闭合环流**：能量在它和谁之间循环？
7. **多层矩阵**：它嵌套在什么更大的结构里？

> **示例**：用这7个问题分析一棵苹果树：
> 收敛核=树干/根系，发散场=果实/花粉，膜=树皮，收发互补=蜜蜂/土壤微生物，闭合环流=光合作用-根系吸收-蒸腾，多层矩阵=果园-生态系统-气候。
> 这套问题同样适用于分析一家医院、一个家庭、一个集市。

### 5.3 跃迁仪式（L癸阶段标配）

每完成一个大循环（如一个学期的核心课题），举行一次结构对话：

**仪式流程（约30分钟）**：

1. 孩子用10分钟向一个完全不懂的人讲清楚"这学期我学了什么结构"
2. 听众问三个问题："这个结构在哪里还出现过？""这个结构的边界是什么？""你哪里还不确定？"
3. 孩子回答后，在"结构地图"上标记这个结构
4. 仪式宣告：这个结构已经是你的了，下一个尺度等着你

> **效果**：能教出去 = 已经内化。教不出去 = 还在丙丁阶段，需要更多循环。

## 六、AI的具体角色

AI不是老师，是两件工具：

| 角色 | 具体功能 | 示例 |
|---|---|---|
| 调试器 | 实时参数反馈 | "你这次温度是32°C，之前28°C效果更好，要不要试26°C？" |
| 路由器 | 个性化下一步推荐 | "你对发酵的菌种变化最感兴趣，下一个循环推荐你做味噌而不是面包" |
| 记录员 | 跨循环数据对比 | 帮孩子整理所有三栏报告，生成参数-结果趋势图 |
| 结构镜 | L5跨领域迁移辅助 | "你说的发酵里的'菌种筛选'，和代码里的什么概念最像？" |

> **原则**：AI处理记忆和模式，人处理判断和价值。村里真正会发酵、会种地、会号脉的人是"师"，AI是"调试工具"。

## 七、生态村特有的学习优势（权重干涉）

生态村的同频环境是天然优势，要主动利用：

- **同龄跨进度配对**：让完成了戊阶段的孩子去教刚到丙阶段的孩子——教的人巩固结构，学的人缩短盲探期
- **跨龄师徒**：每个大孩子绑定一个小孩，跟着完整跑一个真实生产循环（种菜/养鸡/做酱）
- **集体测试日**：每月一次，所有人做同一个实验，不同参数，公开对比结果——这是最自然的"矩阵化测试"

## 八、评估方式

不打分，只记录状态：

| 状态 | 判断依据 |
|---|---|
| 甲-丁（操作期） | 能独立完成操作，知道关键变量 |
| 戊（结构形成） | 能解释为什么，而不只是怎么做 |
| 己-壬（稳定期） | 能教别人，能写操作手册 |
| 癸（跃迁完成） | 能在新领域里认出同一个结构 |

> **唯一的毕业标准**：在5个完全不同的领域里，能认出同一个结构。

## 九、五维发展手册（意魂神魄精）

> 来源整合：归墟场论知识库（意魂神魄精五维拓扑）+ 《阴符七术》（五行五灵七术训练法）
> 两个体系同源，互为补充。知识库给结构定义，七术给训练方法。

### 9.1 总纲：五维是闭合回路，不是独立指标

五维形成一个运行回路：
```
心（锚点）→ 投射意 → 生成神（与外界交互）
→ 产生魂（运动趋向）→ 魄（约束边界）
→ 精（供能）→ 回流心
```

**阴符七术的根本句**："化有正气者：志也、思也、虑也、意也，神其长也。"
四维都是"正气"，神统摄它们。神力不是独立训练出来的，是其他四维稳定后自然升起的场。

**五维与七术的对应**：

| 知识库术语 | 七术术语 | 五行 | 五脏 | 对应训练法 |
|---|---|---|---|---|
| 精力 | 志 | 水 | 肾 | 养志法 |
| 意力 | 意 | 土 | 脾 | 实意法 |
| 魂力 | 思 | 木 | 肝 | 散势法 |
| 神力 | 悤/神 | 火 | 囟 | 盛神法 |
| 魄力 | 虑 | 金 | 肺 | **分威法** |
| 心力 | — | — | — | **转圆法 + 损兑法** |

> 注：实意法中"虑欲深远"提及虑（魄力的五灵），但实意法本体训练的是意力。魄力的专属训练法是分威法；心力不是背景前提，而是七术后两法的专门训练对象。

**七术的三层结构**：
```
养内三法（培养内部五维）：养志法、实意法、盛神法
外用两法（五维转外部输出）：分威法（魄→威势）、散势法（魂→势能）
统合两法（心力的两个面）：转圆法（无穷应变，心在流动中不失圆心）
                          损兑法（机危决断，心在危机时刻不虚）
```

### 9.2 训练有顺序——先内后外，前项稳才能开后项

**阴符七术的关键句**："五脏和，通六腑，精神魂魄固守不动，乃能内视、反听、定志。"

这是一个**能力解锁树**：五维没有稳定，更高层的能力不会出现，强行练是本末倒置。

```
前提：安己（心力的基础状态）
  ↓
第一层：精力（志）——地基，能量储备
  ↓
第二层：魄力（虑）——边界，让精力不散
  ↓
第三层：意力（意）——探针，向外感知
  ↓
第四层：魂力（思）——引擎，方向性驱动
  ↓
第五层：神力（神）——辐射，与外界真实连接
  ↓
贯穿始终：心力——锚点，在整个螺旋中保持不漂移
```

**对教学的含义**：不要在孩子精力不足时练神力（表达/关系），不要在魄力不稳时练意力（广泛观察）。先确认前项状态，再开后项训练。

---

### 9.3 前提：安己

**七术原文**："养志之始，务在安己；己安，则志意实坚。"

安己不是一个训练项目，是所有训练的前提条件。孩子不在"安己"状态时，任何维度的训练效率都极低。

**生态村里的安己场景**：
- 有固定的个人空间和节奏（不是集体统一安排的空间）
- 有一件确定属于自己负责的事（一块地、一只动物、一个工具箱）
- 每天有不被打扰的安静时段（非结构化时间）

---

### 9.4 精力（志）——地基

**结构**：系统的总能量容量，动能+势能的总储备。不是"今天累不累"，是系统能支撑多久、多深的底层容量。

**七术补充**："志者，欲之使也。欲多则心散，心散则志衰。"
精力最大的消耗来源不是劳动，而是**欲望的分散**。方向太多、选择太多，心气散掉，精力跟着衰。

**内部训练**：
- 精力周期觉察：记录一周内哪些时段做事质量最高/最低，找到自己的节律
- 区分正常疲劳与透支：疲劳后休息能恢复；透支后休息也恢复慢——认识自己的透支信号
- 欲望减法：定期问"我现在同时在追几件事？"减少到最重要的1-2件，让心气归一
- 识别精力漏洞：哪些事/人/环境在不知不觉消耗精力

**外部训练**：
- 体力劳动+充分恢复的完整循环（农耕是天然的精力训练，消耗之后必须给足恢复）
- 自然节律同步：日出而作、跟节气走——城市里失去的精力节律，生态村天然具备
- 饮食觉察：发酵食物、当季食物是天然的精力实验室
- 设计高质量恢复环境（睡眠质量比睡眠时长更重要）

**失调信号**：精力不足：做一点事要恢复很久；精力感知钝化：从不觉得累但一直在透支

---

### 9.5 魄力（虑）——边界

**结构**：系统膜的刚性与弹性。不是越硬越好——是**被冲击后能弹回来**的弹性边界。

**七术训练法：分威法**
"分威者，神之覆也。静意固志，神归其舍，则威覆盛矣。威覆盛，则内实坚；内实坚，则莫当。"
分威 = 把内部稳固的魄力向外辐射为威势。不是靠强硬或攻击，而是内部实坚之后，边界自然向外形成威覆。训练逻辑：意要静、志要固，然后边界自然充实有力，无人能破。

> 注："虑欲深远"出现在实意法中，是说意力训练需要虑力（魄力）的深远配合——虑深远才能意定，意定才能神策生。这是两维的协作关系，不是实意法在训练魄力。

**内部训练**：
- 身份清单：写清楚"我是什么/我不是什么"。写得清楚的人魄力有基底，写不清楚的容易被环境塑造
- 觉察接触点反应：当批评/压力/否定来临，第一反应是崩溃、反击、关闭还是弹回？
- 两种失调的自我辨认：**过刚**（稍离舒适区就不适，拒绝新信息）vs **过软**（在不同环境里变成完全不同的人）

**外部训练**：
- 身体纪律：固定作息、规律劳动、武术或太极。魄是金、是有形载体，身体有结构魄力才有基底
- 真实的"说不"场景：在真实人际压力里守住边界，对方继续施压还能守住
- 角色完整进出：完全进入一个角色（修鞋匠/厨师/谈判者），然后完整地走出来
- 接受批评而不崩溃：外部冲击是测试魄力弹性的天然实验

**失调信号**：过刚：拒绝反馈，不愿尝试新事物；过软：被人一说就全盘改变立场

---

### 9.6 意力（意）——探针

**结构**：从心向外投射，识别频率，判定同异，带结论回来。关键是**出+回的完整闭环**，缺任何一半都不算训练。

**七术补充**："实意者，气之虑也。意虑定则心遂安，心遂安则所行不错。"意力的稳定带来心的安定，然后行动才不出错。

**内部训练**：
- 投射觉察：每隔一段时间问"我的注意力现在在哪里？带回来什么了吗？"
- 观察与判断分离：区分"我观察到了X"和"我对X的解读是Y"——意力训练的核心是把这两步拆开
- 向内的意力：把注意力投射到自己的身体感觉/情绪状态上，然后带判断回来

**外部训练**：
- 精细感官训练：蒙眼辨两种土壤、盲品发酵产品、听出动物叫声异常——训练意力的"分辨率"
- 读人读场：进入陌生空间，五分钟内观察到什么？注意到哪些没说出口的东西？
- 调试/找bug：先观察现象，推原因，验证——意力的完整循环
- 跨领域模式识别：在两个不同领域认出同一个结构（这是意力最高级的应用）
- 中医望闻问切练习：四诊是意力训练的完整模板

**失调信号**：散：观察很多但结论带不回来，只是漫游；聚：只向内想，不向外真正观察；吸附：注意力投出去被对象吸住，失去自己的判断立场

---

### 9.7 魂力（思）——引擎

**结构**：改变现状的内在驱动，场的运动趋向。与神力永远反相——**外在最亮眼时魂力结构上最弱；走到尽头卡住时魂力结构上最强**。

**七术补充**："散势法"的失败状态："心虚志溢，意衰威失，精神不专"——这是魂力耗散的样子。内精五气（精力充足）才能有持续的魂力。

**内部训练（情绪入口）**：
- 情绪识别三步：①叫出名字（"我现在是愤怒/热爱/恐惧"）→ ②问方向（"这个情绪想让我改变/靠近/离开什么？"）→ ③趁热启动一个小动作，让能量落地而不是散掉
- 价值观澄清：我真正在乎什么？这件事值得我持续推吗？魂力是有方向的加速度，不是盲目冲动
- 坐在卡住里：学会在走到尽头时不逃跑——那个难受的时刻是魂力结构上最充沛的位置

**外部训练（环境势能入口）**：
- 不可抗力设计：自然节律（节气/生命周期）、公开承诺、生命依赖（有东西真的在等你）、团队互依
- 背水一战情境：切断退路，让"继续"变成唯一选项
- 真实截止日期：不是自己给自己的，而是外部强制的

> **教师最难的功课**：不要在孩子卡住的时候帮他。那个难受的时刻是魂力结构上最充沛的位置，帮他等于替他把这股力量用掉了。

**失调信号**：不足：遇阻立刻绕路，换了很多方向每个都没跑完；过猛而缺魄力：冲动烧穿自己

### 9.8 神力（悤/神）——辐射场

**结构**：两个系统交互后产生的辐射场。单人无法产生神力，必须有真实的他者。神力是其他维度稳定后**自然溢出**的场，不是独立训练出来的。

**七术关键句**："静意固志，神归其舍，则威覆盛矣。"意静、志固，神自然归位，威力自然辐射。强行输出是代偿，不是神力。

**内部训练（信号清晰度）**：
- 问"我现在真正在辐射什么"：不是我说了什么，而是我的场在传递什么
- 区分表演（代偿）和真实辐射：表演是神力弱时的补偿行为，越用力说越没有影响力
- 沉默时的在场练习：不靠语言，只靠存在感。感受自己在不说话时，场域是什么状态
- 神力弱的觉察：说了很多但对方没被触动；在场但"不存在"

**外部训练（真实他者入口）**：
- 建立亲密关系：最深层的双系统耦合训练，能真正被对方感知，也能感知对方
- 教学：最纯粹的神力测试——能立刻感知对方有没有接住
- 调解/翻译：在两套不同语言/系统之间建立连接（控制论的中介节点训练）
- 在陌生群体中建立存在感：不靠头衔，不靠话多，靠真实的场域辐射
- 团队共建：和别人一起创造共同的目标/语境/回忆（第三归墟）

**失调信号**：不足：说很多但触达不到人，存在感弱；过强而精力不足：灿烂但很快耗尽，靠消耗自己支撑辐射

### 9.9 心力——锚点（转圆 + 损兑）

**结构**：系统本体的基座厚度与惯性。心力越大，能承受更长周期没有反馈而不漂移。

**七术训练法：转圆法 + 损兑法**——心力有两个面，分别对应两法：

**转圆法**（心力的流动面）："转圆者，无穷之计也。以原不测之智而通心术，神道混沌为一。以变论万类，说意无穷。"
转圆 = 在万千变化中保持有圆心——转来转去，圆心不移。心力强的人，无论外部如何变化，内核方向不变；遭遇任何情境，都能"或圆或方，或阴或阳"地应对，而不是在变化中迷失自己。

**损兑法**（心力的决断面）："损兑者，机危之决也。辞不烦而心不虚，志不乱而意不邪。"
损兑 = 在关键危险时刻做出决断。心不虚、志不乱、意不邪——这是心力稳固时的状态描述。心力弱的人在机危时刻迷失（心虚、志乱），心力强的人能在极端压力下保持清醒、做出准确判断。

**内部训练**：
- 独处：一个人和自己待着，不逃进手机/娱乐/他人。这是心力的充电场
- 一致性检查：我这一年在坚持什么？和三年前相比，核心方向有没有漂移？
- 被否定时的内部观察：批评/失败来了，我的核心方向动了吗？动了是心力弱；没动但能听进去是心力健康

**外部训练**：
- 跨季度慢反馈项目：春分种下，秋分才知道结果——农耕是最天然的心力训练场，不可替代
- 强社会压力下保持方向：家庭期待、同伴压力、集体否定——在这些时候不漂移，是心力真正在工作
- 社群见证：有人长期了解你，见证你的一致性——外部的心力锚点
- 承诺一件长期的事：不是"我想做"，而是"我选择做，无论中间遇到什么"

**失调信号**：不足：在不同环境里变成完全不同的人，一被否定连原来相信的也开始怀疑；过强：稳而封闭，无法与外界真正连接

### 9.10 六维配对——训练时同步注意

| 配对 | 关系 | 失衡危险 |
|---|---|---|
| 精 + 魂 | 精力是魂力的燃料 | 魂力冲但精力空 = 快速燃尽 |
| 魄 + 意 | 魄划边界，意在边界内外投射 | 意力广但魄力软 = 观察失去立场 |
| 神 + 精 | 神力是辐射，精力是辐射的能量来源 | 神强精弱 = 灿烂但耗尽 |
| 魄 + 心 | 魄是外边界，心是内锚点 | 只有魄没有心 = 防御壳；只有心没有魄 = 锚而无界 |
| 意 + 魂 | 意力看到方向，魂力推着走 | 有意无魂 = 分析瘫痪；有魂无意 = 盲目冲 |

### 9.11 五维诊断地图（教师用）

观察孩子遇到困难时：

```
卡住了走不动
→ 观察魂力：这是驱动最强的时刻，他在坐着还是在逃跑？

被人否定
→ 观察心力：方向有没有漂移？

和别人起冲突
→ 观察魄力：边界是刚性崩溃还是弹性回来？

需要影响别人
→ 观察神力：有没有真正的连接产生？还是在表演？

需要做判断
→ 观察意力：观察有没有真正回流成有用的结论？

持续工作之后
→ 观察精力：容量还剩多少？有没有在透支？
```
